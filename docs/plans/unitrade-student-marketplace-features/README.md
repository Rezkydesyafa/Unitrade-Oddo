# UniTrade Student Marketplace Feature Plans

Folder ini berisi rencana per fitur untuk konsep baru UniTrade:

- Mode katalog tetap diizinkan.
- Transaksi luar website tidak dilindungi escrow/refund UniTrade.
- Fee upload produk wajib dibayar sebelum publish.
- Checkout website menjadi jalur proteksi resmi.
- Payout seller dimulai manual oleh admin.
